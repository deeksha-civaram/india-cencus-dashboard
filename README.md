📊 India Census 2011 Dashboard

This project is an interactive data visualization dashboard built using Streamlit.

🚀 Features

- Data cleaning and preprocessing
- Interactive filters
- Visualizations (bar chart, histogram, scatter plot, heatmap)
- Key insights

🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Streamlit

▶️ How to Run

pip install streamlit pandas matplotlib seaborn
streamlit run app.py

📌 Output

An interactive dashboard to explore population, growth rate, and density across Indian states and union territories.
